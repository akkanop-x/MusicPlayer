## Brief

CI skeleton ที่รัน lint + typecheck + unit test (ตาม roadmap):

- GitHub Actions workflow ที่ `.github/workflows/ci.yml`: checkout → setup pnpm + Node → `pnpm install --frozen-lockfile` → `pnpm lint` → `pnpm typecheck` → `pnpm test`
