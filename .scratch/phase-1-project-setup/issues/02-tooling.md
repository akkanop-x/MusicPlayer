Status: resolved

## Brief

ติดตั้ง toolchain ระดับ monorepo:

- Tailwind CSS ใน `apps/web` (รุ่นใหม่ล่าสุด — ถ้าเป็น v4 ใช้ Vite plugin ก็พอ)
