# 01 — pnpm workspace skeleton

Status: resolved
Category: enhancement

## Brief

สร้าง monorepo skeleton ด้วย pnpm workspace ตาม [backend.md](../../../docs/backend.md) §1 และ [frontend.md](../../../docs/frontend.md)

- Root: `package.json` (private) + `pnpm-workspace.yaml` (`apps/*`, `packages/*`)
- `apps/web` — Vite + React + TypeScript (template react-ts) — หน้า login placeholder ง่าย ๆ (ฟอร์ม email/password ไม่ต้องยิง API จริง)
- `apps/server` — Fastify + TypeScript — boot ได้, มี `GET /health` → 200 `{ ok: true }`, โครงโฟลเดอร์ตาม backend.md (routes/services/repositories/config/plugins — วางโครงไว้ก่อน ยังไม่ต้องมี service จริง)
- `packages/shared` — TS package สำหรับ types/pure logic ที่แชร์สองฝั่ง (Phase 1: วางโครง + export type พื้นฐาน เช่น error shape `{ error: { code, message, details? } }`)
- `.gitignore` (root) — รวม `.env`, `node_modules`, `dist`, `.env.*` (ยกเว้น `.env.example`)
- `.env.example` ตาม backend.md §5: `DATABASE_URL`, `LAVALINK_URL`, `LAVALINK_PASSWORD`, `RESOLVER_URL`, `JWT_SECRET`, `REFRESH_SECRET`, `CORS_ORIGIN`, `PORT`

## DoD

- `pnpm install` แล้ว `pnpm -r build` ผ่านทั้งสาม package
- `GET /health` ตอบ 200
