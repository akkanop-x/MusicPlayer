# Spec: Phase 1 — Project Setup

> Status: triaged 2026-09-20 จาก [docs/roadmap.md §Phase 1](../../docs/roadmap.md)
> Phase 0 ได้รับการอนุมัติจากผู้ใช้แล้ว (2026-09-20) — เงื่อนไข dependency ผ่าน

## Goal

Skeleton monorepo + infra รันได้ด้วยคำสั่งเดียว (`docker compose up`)

## Scope (จาก roadmap)

- pnpm workspace: `apps/web` (Vite React TS), `apps/server` (Fastify TS), `packages/shared`
- Tailwind + ESLint + Prettier + Vitest setup, `.env.example`, `.gitignore` (รวม `.env`)
- `docker-compose.yml`: postgres + lavalink + resolver (placeholder) + server + web
- Drizzle init + migration แรก (ตาม [database.md](../../docs/database.md))
- CI skeleton: lint + typecheck + unit test

## Definition of Done

`docker compose up` → ได้หน้า login placeholder + `/health` ตอบ 200 + migration run อัตโนมัติ + CI เขียว

## Constraints จาก docs (ต้องเคารพตั้งแต่ Phase 1)

- Node.js + Fastify + TypeScript layered architecture ตาม [backend.md](../../docs/backend.md) (routes → services → repositories)
- Env ผ่าน zod fail-fast ตอน boot: `DATABASE_URL`, `LAVALINK_URL`, `LAVALINK_PASSWORD`, `RESOLVER_URL`, `JWT_SECRET`, `REFRESH_SECRET`, `CORS_ORIGIN`, `PORT`
- Error shape เดียว: `{ error: { code, message, details? } }`
- PostgreSQL 16 + Drizzle ORM + UUID PK + TIMESTAMPTZ ทุก table ตาม [database.md](../../docs/database.md)
- Zero storage: ไม่มี media ลง disk (ADR-008) — ไม่มีผลต่อ Phase 1 โดยตรง แต่ห้ามวาง infrastructure ที่ขัด

## Non-goals (ของ phase นี้)

- การเชื่อมต่อ Lavalink จริง (Phase 2), auth จริง (Phase 2+), UI จริง (Phase 4+)

### 2026-09-20 — ตรวจ DoD (AI)

> _This was generated by AI during triage._

DoD ผ่านครบ ตรวจด้วยของจริง:

- `docker compose up --build` ลุกครบ 5 services: postgres (healthy), lavalink, resolver, server (healthy), web
- หน้า login placeholder render จริงใน browser ที่ http://localhost:8080 (ยืนยัน DOM: ฟอร์ม email/รหัสผ่าน/ปุ่ม)
- `GET :3101/health` → HTTP 200 `{"ok":true}` (host port 3101 เพราะ 3001 ถูก process อื่นของเครื่องใช้)
- migration run อัตโนมัติ: ตารางครบ 10 ตาม database.md + extension `pg_trgm` ถูกสร้าง
- `pnpm lint` / `pnpm typecheck` / `pnpm test` เขียว (7 tests) — CI workflow อยู่ที่ `.github/workflows/ci.yml` (จะทำงานเมื่อ push ขึ้น GitHub — repo ยังไม่ได้ git init)

ปัญหาที่เจอและแก้ระหว่างทาง (บันทึกไว้เป็นบทเรียน):

1. pnpm 12 ย้าย `onlyBuiltDependencies` ไปที่ `pnpm-workspace.yaml` (`allowBuilds`) — ต้องอนุมัติ esbuild
2. drizzle-orm 0.44 import path ของ migrate คือ `drizzle-orm/node-postgres/migrator` (ไม่ใช่ `/migrate`)
3. Fastify จัดการ 404 ผ่าน `setNotFoundHandler` แยกจาก `setErrorHandler` — ต้อง set ทั้งคู่ให้ตอบ error shape เดียว
4. healthcheck ใน alpine ต้องใช้ `127.0.0.1` ไม่ใช่ `localhost` (resolve เป็น IPv6 แต่ server bind IPv4)
5. `.dockerignore` ที่มี `**/docker` ตัด `nginx.conf` ของ web หาย — ลบออก
