## Work

1. env: server ใช้ `SPOTIFY_CLIENT_ID/SECRET` เดียวกับ LavaSrc — เพิ่ม passthrough ใน compose (server service) + optional ใน env.ts (optional เพราะ fail-soft)
2. `SpotifyWebApiService`: client credentials grant (token cache จนหมดอายุ), `GET /v1/search?type=artist&q=<artist>&limit=1` → `genres[]`; normalize lowercase/trim
3. Hook ใน SearchService: หลัง upsert track ใหม่ (นับเฉพาะ track ที่**เพิ่งสร้าง**, ไม่ re-enrich ของเก่า) และ sourceName=youtube → เติม genres จาก artist
4. Fail-soft: ไม่มี credentials / ยิงไม่สำเร็จ / rate-limited → ข้าม (genres ว่าง) + log warn; ไม่มีผลต่อ search response
5. กัน flood: ต่อ request จำกัด enrich (เช่น 3 artist/ครั้ง) — ที่เหลือไปเติมภายหลัง

## Acceptance

- unit: token cache + normalize + ไม่มี credentials → ไม่ยิง
- จริง (เมื่อ user ใส่ credentials): search → `tracks.genres` มีค่า
