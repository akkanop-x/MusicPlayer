# 01 — Minimal Auth (register/login/refresh/logout/me + requireAuth)

Status: resolved

> _This was generated by AI during triage._

## Context

`/stream` ต้อง auth ด้วย session cookie (security.md §8.6) แต่ auth ยังไม่มีใน codebase และไม่มี phase รับผิดชอบ — user ตัดสินใจ 2026-09-20 ให้ดึงมาทำก่อนใน Phase 3 ตาม api.md §2 + ADR-006

## Work

1. Migration ใหม่ (drizzle-kit generate): ตาราง `refresh_tokens` — id UUID PK, user_id FK CASCADE, token_hash (sha256 hex, NOT NULL, UNIQUE), series_id (UUID, NOT NULL), expires_at, revoked_at NULL, created_at; INDEX(user_id), INDEX(series_id)
2. dep: `argon2` (server); JWT sign/verify ด้วย node:crypto (HMAC-SHA256 เขียนเอง ~30 บรรทัด ไม่เพิ่ม dep jsonwebtoken)
3. `AuthService`:
   - register(email lowercase, password ≥ 8, displayName) → hash argon2id → สร้าง user + user_settings row
   - login → verify → issue access (JWT 15 min, claims { sub }) + refresh (opaque 32B base64url, 30 days)
   - refresh: เก็บ**เฉพาะ hash**; ใช้แล้ว revoke + issue ใหม่ใน series; **reuse detection** → revoke ทั้ง series_id
   - logout: revoke series + ลบ cookie
4. Routes `/api/v1/auth/*` + `GET /me`: ตาม api.md §2 (register Public, login Public + 429 ภายหลัง, refresh/logout อ่านจาก cookie, me Bearer)
5. Cookie: `refresh_token` httpOnly + SameSite=Strict + path=/api/v1 (+ Secure เมื่อ prod — dev ผ่าน http ต้องปิด)
6. `plugins/requireAuth.ts` — verify Bearer → request.user = { id } ; ไม่ผ่าน → 401 UNAUTHENTICATED
7. Tests: register→login→refresh (rotate + token เก่าถูก revoke) → reuse ตัวเดิม → 401 + ทั้ง series โดน revoke; me ด้วย/ไม่มี token; validation

## Acceptance

- tests เขียว hermetic (mock/db จริง? — ใช้ db จริงผ่าน testcontainers ไม่ได้ → ให้ AuthService รับ seam ที่ inject db function ได้ หรือทดสอบผ่าน smoke จริง + unit ที่ pure parts)
- lint/typecheck ผ่าน
