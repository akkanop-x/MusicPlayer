## Lessons learned

- client เป็นผู้รู้ position จริงเมื่อไม่มี WS — การตัดสิน "previous restart vs pop
  history" ต้องใช้ position ฝั่ง client (engine) ไม่ใช่ server
- ตัวจำกัด concurrent ของ endpoint ที่ stream/hijack ต้อง release ตั้งแต่ต้น request
  (รวมช่วง await) ไม่ใช่ตอน response เสร็จ — client abort ได้ทุกเมื่อ
