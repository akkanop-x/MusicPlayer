## งาน

1. `tracks.repo.ts` — เพิ่ม `searchTracks(db, q, limit)` ใช้ pg_trgm:
   `similarity(title|artist, q) > 0.3 OR ILIKE '%q%'` ORDER BY GREATEST(similarity) DESC
   → map เป็น row เต็ม (isLiked=false) และ `findTrackDTOs(db, ids)` (batch, inArray,
   คงลำดับตาม ids ที่ส่งมา)
2. `SearchService` v2 — deps เพิ่ม `searchLibrary(q, limit)`; search(q, {source, limit, offset}):
   - ยิง lavalink + library พร้อมกัน; library error → degraded "library" (ไม่ fail)
   - merge library ก่อน remote, dedupe by id, slice offset..offset+limit
   - lavalink error → มีผล library → 200 {tracks, sources:{available:["library"], degraded:[source]}}
     / library ว่าง → 503 UPSTREAM_UNAVAILABLE (เดิม)
3. `search.routes.ts` — requireAuth(jwtSecret) + `?offset=` (int ≥ 0 default 0) +
   searchGuard 30 req/min/user (security/searchGuard.ts — pattern streamGuard) → 429
4. `tracks.routes.ts` (ใหม่) — GET /tracks/:id (UUID → 404 TRACK_NOT_FOUND/NOT_FOUND),
   GET /tracks?ids=a,b,c (≤ 50, unique) → { tracks: TrackDTO[] } — requireAuth
5. `app.ts` — wire ครบ (search routes รับ jwtSecret + library search จาก db; tracks routes)
