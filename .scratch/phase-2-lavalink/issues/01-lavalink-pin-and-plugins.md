## Work

1. `docker-compose.yml`: pin `ghcr.io/lavalink-devs/lavalink:4.2.2` (ตรวจแล้ว — release ล่าสุด 2026-03-06)
2. `services/lavalink/application.yml` ใหม่ — เทียบกับ application.yml.example ของ tag `4.2.2` (ดึงแล้วผ่าน gh api):
   - `lavalink.server.sources`: youtube **false** (built-in deprecated), bandcamp/soundcloud/http **true**, twitch/vimeo/nico/local **false**
   - plugins ที่ `lavalink.plugins` (list): youtube-source `dev.lavalink.youtube:youtube-plugin:1.18.2` + LavaSrc `com.github.topi314.lavasrc:lavasrc-plugin:4.8.3` (repo maven.lavalink.dev/releases เป็น default ของ v4 — ไม่ต้องระบุก็ได้แต่ระบุชัด)
   - plugin config ที่ **root** `plugins:` (ตาม README ทั้งสองตัว):
     - `youtube:` enabled, allowSearch/DirectVideoIds/DirectPlaylistIds true, clients [MUSIC, ANDROID_VR, WEB, WEBEMBEDDED]
     - `lavasrc:` providers (ISRC→ytsearch fallback), `sources.spotify: true`, `spotify: { clientId: "${SPOTIFY_CLIENT_ID:}", clientSecret: "${SPOTIFY_CLIENT_SECRET:}", countryCode: TH, resolveArtistsInSearch: false }`
   - เก็บ `logging.logback.rollingpolicy` เดิม; password ผ่าน `"${LAVALINK_PASSWORD}"`
3. `docker-compose.yml`: passthrough `SPOTIFY_CLIENT_ID` / `SPOTIFY_CLIENT_SECRET` เข้า container lavalink (default ว่าง)
4. `.env.example`: เพิ่ม SPOTIFY_CLIENT_ID/SECRET (comment: สร้างที่ developer.spotify.com dashboard)

## Acceptance

- `docker compose up -d lavalink` → container healthy, log แสดง plugins โหลดสำเร็จ (youtube / lavasrc)
